Privacy Policy

How bridgeengine.tech handles data. Last updated: 20 October 2026.

Overview

This website presents the BRIDGE master thesis project. This policy explains the limited data processing that takes place when you visit the site or use the live demo, and it applies to bridgeengine.tech only.

What this site does not do

  • No cookies are set by this website.
  • No advertising and no cross-site or cross-device tracking.
  • No sale or sharing of personal data with advertisers or data brokers.
  • No registration, so we do not collect names, email addresses, or account data.

Analytics

This site uses Umami, a cookieless, privacy-focused web analytics service, hosted on Umami Cloud. It records aggregated, non-personal usage statistics: which pages are viewed, the referring page, browser and operating system family, device category, and an approximate country derived from your IP address. The IP address itself is not stored, no unique identifier is placed on your device, and your visit is not linked to other websites' analytics. Aggregated statistics are kept only as long as the site is operated. You can block analytics entirely with any content blocker or “do not track” setting without affecting the site's functionality.

Live demo

The live demo lets you run graph layout algorithms in the browser. When you execute a layout through the network mode, the code and parameters you enter are transmitted to the demo's execution backend, processed to produce the requested result, and are not used for profiling, advertising, or any other purpose. Inputs are not published. Avoid submitting confidential or personal information in demo inputs, since execution output may be shown back to you.

Third-party services

  • Hosting. The site is served as a static website by GitHub Pages (GitHub, Inc.). Its servers process standard request data (for example IP address and user agent) in temporary logs.
  • Fonts and demo libraries. Fonts and the demo's JavaScript libraries are loaded from Google Fonts and the esm.sh CDN; your IP address is transmitted to these providers to deliver the files.
  • Analytics. Umami Cloud, as described above.

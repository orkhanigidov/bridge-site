Privacy Policy

How bridgeengine.tech handles data. Last updated: 21 October 2026.

Overview

This website presents the BRIDGE master thesis project. It sets no cookies, shows no advertising, and requires no registration. This policy describes the limited data processing that takes place when you visit the site or use the live demo, and it applies to bridgeengine.tech only.

Analytics

This site uses Umami, a cookieless, privacy-focused web analytics service, hosted on Umami Cloud. It records aggregated statistics — pages viewed, browser and operating system family, device category, and an approximate country — without storing your IP address or placing identifiers on your device. Statistics are kept only as long as the site is operated, and blocking analytics with a content blocker does not affect the site's functionality.

Live demo

When you execute a layout through the demo's network mode, the code and parameters you enter are transmitted to the execution backend solely to produce the result — they are not published or used for any other purpose. Avoid submitting confidential or personal information in demo inputs.

Third-party services

  • Hosting. The site is served as a static website by GitHub Pages (GitHub, Inc.). Its servers process standard request data (for example IP address) in temporary logs.
  • Fonts and libraries. Fonts and the JavaScript libraries are loaded from Google Fonts and the esm.sh CDN; your IP address is transmitted to these providers to deliver the files.
  • Analytics. Umami Cloud, as described above.
